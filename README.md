# 🎰 Termo Melhorado - Edição Competitiva

Uma versão aprimorada, interativa e competitiva do clássico jogo **Termo (Wordle)**. O projeto conta com um sistema completo de progressão de Elos (Ranked), modos multi-tabuleiros dinâmicos (até 4 telas simultâneas), eventos relâmpago com roleta de multiplicadores e customização de perfil com cosméticos desbloqueáveis.

🔗 **Acesse o jogo rodando ao vivo aqui:** [Termo Melhorado no Render](https://termo-melhorado.onrender.com)

---

## 🚀 Funcionalidades Principais

* **Modo Ranqueado de 3 Níveis:**
  * **Nível 1 (1 Quadro):** O modo clássico para aquecer os motores.
  * **Nível 2 (2 Quadros simultâneos):** Desafio duplo com multiplicador de pontos de `2x`.
  * **Nível 3 (4 Quadros simultâneos):** Modo insano com limite estendido de linhas e multiplicador de `5x`.
* **Sistema de Elos e Ranking:** Ganhe PDL (pontos) ao acertar os termos e suba do elo **Ferro** até o **Radiante**. Cuidado: perder um round sem acertar nada gera uma penalidade grave de `-15.000 PDL`.
* **Eventos Relâmpago (Flash Events):** Eventos automáticos que acontecem 3 vezes ao dia (00h, 08h e 16h) com duração de 2 horas. Durante o evento, você pode girar uma roleta grátis para garantir bônus de pontuação de `2x`, `3x` ou até `5x`.
* **Loja de Cosméticos Integrada:** Desbloqueie e equipe avatares exclusivos e bordas de perfil temáticas baseadas no seu nível de pontuação atual.
* **Persistência de Dados:** Sincronização automática com banco de dados para salvar seus pontos, cosméticos e temas escolhidos.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas e leves para garantir uma experiência fluida:

* **Front-end:** HTML5, CSS3 (Variáveis nativas para sistema de temas) e JavaScript Assíncrono (Vanilla JS).
* **Back-end:** Node.js com Express para gerenciamento de rotas, controle de sessão do usuário e sincronização de dados.
* **Hospedagem:** [Render](https://render.com/)
